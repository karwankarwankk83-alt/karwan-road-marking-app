ئەپێکی پێشکەوتووی هێڵکێشانی شەقام – کاروان سەعید

ئەم وەشانە Progressive Web App (PWA) ـە و لە Android، iPhone و Computer کار دەکات.

تایبەتمەندییەکان:
- ناوەڕۆکی ڕاستەقینەی 13 بەشی کتێب + پاشکۆکان
- خشتەکانی ناو Word لە ناو Reader
- Full-text Search
- Reading Progress و Continue Reading
- Favorites و Notes
- Gallery ـی وێنەکانی Road Marking
- Field Calculators: Continuous, Broken, Zebra, 2K Mix
- Project Estimator + CSV Export
- Project / QC / HSE Checklists
- Standards Index
- Engineering Drawings PDFs
- Dark/Light Mode و گۆڕینی قەبارەی نووسین
- Offline Mode و PWA Install

چۆنیەتی تاقیکردنەوە لە Windows:
1) فایلە ZIP ـەکە Extract بکە.
2) index.html دەتوانیت ڕاستەوخۆ بکەیتەوە بۆ Preview.
3) بۆ PWA/Offline Install، لە فولدەری ئەپ Command Prompt بکەرەوە و بنووسە:
   python -m http.server 8080
4) لە Chrome بکەرەوە: http://localhost:8080
5) Install App / Add to Home Screen هەڵبژێرە.

تێبینی: بۆ گۆڕینی ئەمە بۆ APK ـی Native دواتر دەتوانرێت Capacitor/Android Studio بەکاربهێنرێت.
